# The lettering on the doors

Every face here is served from this site rather than fetched from someone
else's server, so the wall keeps its lettering whatever happens to a CDN,
and so it still works offline once the site is installed as an app.

Each file has been cut down to letters, digits, spaces and a little
punctuation — all a tag ever says — which is why thirty-six faces come to
about the weight of one photograph.
